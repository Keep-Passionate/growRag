## 方向一｜经验辅助的低成本查询选择

| 阅读级别 | 论文 | 学习重点 |
|---|---|---|
| 方向必读 | [QPP Query Variant Selection](https://doi.org/10.1145/3805712.3808571) | 比较同一信息需求的多个查询候选；区分检索前/后预测、排名效果与答案效果。QSD(Pre) 已使用历史近邻查询效果。 |
| 方向必读 | [ReformIR / When More Reformulations Hurt](https://doi.org/10.1145/3805712.3809721) | 用原查询锚定的排序反馈和轻量替代模型，在多改写检索结果中控制预算和漂移。 |
| 方向必读 | [RAQG-QPP（TOIS）](https://doi.org/10.1145/3815198) | 检索历史查询，必要时以它们为示例生成新变体，改善 QPP；定向读意图保真但词形不适合语料的案例。 |
| 方向必读 | [ReFormeR](https://doi.org/10.1007/978-3-032-21300-6_30) | 把有效查询改写对提炼为显式模式，再选择并应用到新问题。重点追踪模式来源、选择依据和具体改动。 |
| 方向必读 | [RRM](https://arxiv.org/abs/2607.28156) | 明确适用条件、证据要求、失败模式和查询调整；程序性记忆辅助检索，答案仍依赖当前证据。 |
| 基础必读 | [Query Rewriting](https://aclanthology.org/2023.emnlp-main.322/) | 先分清原问题、检索表达与最终回答。Rewrite–Retrieve–Read 可以冻结检索器和回答器，改写器另行提示或训练。 |
| 选读 | [Query2doc](https://aclanthology.org/2023.emnlp-main.585/) | 生成伪文档以扩充检索表达，理解 expansion 与简单同义改写的差别。 |
| 选读 | [HyDE](https://aclanthology.org/2023.acl-long.99/) | 先生成假想文档，再用它的稠密表示检索真实文档。 |
| 选读 | [EPR](https://aclanthology.org/2022.naacl-main.191/) | 用下游任务反馈训练示例检索器；有用的例子不必是词面最像的例子。 |
| 选读 | [ExpWeaver：Rethinking Experience Utilization](https://arxiv.org/abs/2605.07164) | 将经验作为可选资源，学习何时调用；在实际调用位置做经验移除对照。 |
| 选读 | [Adaptive-RAG](https://aclanthology.org/2024.naacl-long.389/) | 按问题选择无检索、单次或多步检索路径，学习从实际路径效果构造选择标签。 |
| 选读 | [RAG-QPP（TOIS）](https://doi.org/10.1145/3827605) | 利用检索后的语义、词汇与分数分布特征预测检索质量，再调整检索深度；适配黑盒生成器。 |
| 选读 | [Q2EI](https://doi.org/10.18653/v1/2026.findings-acl.1791) | 把领域中的通俗描述压缩成实体导向的查询，提示我们改写也可以做减法，而不只是补词。 |
| 选读 | [SMR / From Token to Action](https://doi.org/10.18653/v1/2025.findings-emnlp.371) | 用 REFINE、RERANK、STOP 离散动作管理检索推理，检查冗余、token 成本和意图对齐。 |
| 选读 | [RECAP](https://doi.org/10.18653/v1/2026.findings-eacl.105) | 从多轮对话澄清用户当前目标，研究歧义、含糊和变化中的意图。 |
| 选读 | [WeWrite / When & How to Write](https://doi.org/10.1145/3805712.3808395) | 在个性化视频搜索中先判断是否需要改写，再处理历史偏好、当前需求和索引词汇的对齐。 |
| 选读 | [Am I on the Right Track?](https://ceur-ws.org/Vol-4199/paper3.pdf) | 分析 Agentic RAG 各轮搜索的 QPP、轮数与最终答案关系，理解搜索过程信号。 |

## 01. QPP Query Variant Selection

[Can QPP Choose the Right Query Variant? Evaluating Query Variant Selection for RAG Pipelines](https://doi.org/10.1145/3805712.3808571)

- 级别：方向必读；SIGIR 2026 主会。
- 做了什么、学什么：比较同一信息需求的多个查询候选；区分检索前/后预测、排名效果与答案效果。QSD(Pre) 已使用历史近邻查询效果。
- 重合与边界：加 QPP、加历史查询或先选后执行，都不能单独宣称创新。检索后 QPP 已经支付候选检索成本。
- 精读：预测器定义、实验设置、检索与生成效用差异；配套代码成本审计。
- 自检：选择器分数最高，与实际答案最好的事后上界有什么区别？
- 元数据核验：2026-09-05；[来源](https://doi.org/10.1145/3805712.3808571)。

- 精读：反馈、surrogate、查询权重与预算实验。
- 自检：我们的提升来自历史，还是一个已有的更好排序器？
- 元数据核验：2026-09-08；[来源](https://api.crossref.org/works/10.1145/3805712.3809721)。

## 10. Sufficient Context

[Sufficient Context: A New Lens on Retrieval Augmented Generation Systems](https://proceedings.iclr.cc/paper_files/paper/2025/hash/33dffa2e3d2ab74a783d1a8c292f66d9-Abstract-Conference.html)

- 级别：方向必读；ICLR 2025 主会。
- 做了什么、学什么：区分上下文足够回答与模型实际答对；理解充分性和选择性回答。
- 重合与边界：证据足够不是答案必对，证据不足也不等于应无限检索或一律拒答。
