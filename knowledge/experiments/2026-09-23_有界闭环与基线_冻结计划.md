## 方法与成本

BASE1 / FRESH1 / S2G_GAP2 / REFLECTIVE2 / ADAPTIVE_NO_MEMORY2 / ADAPTIVE_MEMORY2。

S2G_GAP2、REFLECTIVE2 共享 BASE 第一轮。S2G_GAP2 以必要项 description 代替原 target/slot，原 q 追加最多3项，0次新改写 API；训练 judge 替换为固定模型提示词。是 clean-room 同底座适配，不声称复现原论文 LoRA 结果。

每轮 top4 句子 BM25；Reader 新证据优先去重，最多8条；最多2次完整 RAG（非2次额外检索）。此轻量 distractor 候选环境不是全维基开放检索。

冻结模型 `qwen3.7-flash-2026-07-15`，temperature=0、thinking=false、输出最多1536 tokens。最高250 API 请求、30分钟，本轮子限3元，承接项目累计50元授权；启动前607历史请求、已知估算0.0897564元、保守预留0.7132028元、1历史费用未知，不能把未知当0。
