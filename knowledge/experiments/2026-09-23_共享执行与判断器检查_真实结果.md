第1条有语言约定问题：开放世界下，“which of A or B”可能被理解为必须证明唯一；“2014年加入”对现在成员身份也有轻微时态歧义。因此不称它数学意义上错误。准确说法是：**它没有稳定遵循当前 prompt 里“无冲突时正向见证即可”的任务约定。**

第8条的非法输出是 `"useful_gain": ["lumen:0"]`；需要的是 true / false / null。不能未经预注册把“非空列表”转换成 true：列表只告诉我们模型提了哪个 ID，不能替代它对有用性的明确判断。

JSON object 本来就只管语法。官方文档将 JSON Schema 区分为进一步约束字段结构和类型，并列出 Qwen3.7-Flash 支持；本项目仍保留本地校验，尤其不能据此推断语义正确。[百炼结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)
