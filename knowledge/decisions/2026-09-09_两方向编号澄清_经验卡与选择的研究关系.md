# 两个方向不再换编号：经验卡为选择提供什么信息

日期：2026-09-09。研究讨论补充，不是新算法定稿，不启动新运行代码或付费实验。

## 1. 纠正层次和编号

用户沿用的方向一是“怎样选到值得执行的改写”，方向二是“经验必须记住哪些适用条件”。后续仍沿用此编号。09-08 文档将表示列为“研究问题一”是写作组织建议，不代表用户决定交换主辅关系。

- **方向一／主要任务与评价目标**：在有限预算下，决定不改写、现场改写或经验辅助改写；最终看是否比同条件的现场修复更好、更省。
- **方向二／紧密配套的方法研究**：经验应保留什么，才能帮助上述选择。不是另建一套记忆系统，也不以 JSON 字段更多作为贡献。
- **有限修复循环／使用场景**：当前证据→选动作→执行→检查→继续或停止。首轮先固定一个决策点，不同时优化全部循环。
- **长期维护／后续扩展**：合并、衰减、版本替换保留规划，不混入首轮表示对照。

可采用的论文问题仍是：**相同历史来源和执行预算下，怎样保留对当前决策必要的经验信息，使系统少用错经验，同时保留相对现场修复的真实收益？** 此为研究假设，不是已验证的创新。

## 3. 六种卡保留，分清三个独立设计轴

详细结构和同源例子沿用 [09-08 六种经验卡方案](2026-09-08_两条主线对齐_经验卡六种表示与精读顺序.md)。本次不生成一套新编号。

| 卡 | 记什么 | 最想验证的价值 | 最主要风险 |
|---|---|---|---|
| M1 具体改写对 | 原查询、实际新查询 | 具体词汇操作是否已足够 | 旧实体带入、适用原因隐含 |
| M2 通用摘要 | 一条自然语言经验 | 简洁经验能否迁移 | 抽象过头；但优质摘要也可以包含条件 |
| M3 动作模板 | 操作、变量、约束 | 可执行操作是否比笼统教训更有效 | 会执行但不会选 |
| M4 状态—动作—预期变化 | 当时观察、操作、待补证据目标 | 当前状态是否帮助定向修复 | 状态误判、内容膨胀；不适合伪装纯检索前信号 |
| M5 条件—动作—核查 | 支持、禁用、未知条件；动作与检查 | 哪些信息能避免误用和误拒 | 条件幻觉、过严、验证开销；结构已与近邻重合 |
| M6 短卡＋按需来源 | 短视图、必要时读原始片段 | 平均读取成本与细节的折中 | 隐藏额外信息和延迟；不是天然更省 |

三条轴不能混在同一对照里：

1. **动作轴**：同义改写、扩写、拆分等。解决词汇不匹配不一定需要结构缺口。
2. **信息轴**：只给操作，还是给条件、源状态、反馈等。
3. **生成时点轴**：离线源经验摘要，还是拿到当前题后重新生成适配笔记。后者接近 QCR，需计入在线写笔记成本，不能只记更短的最终输入。

“结构化”还包括另一个易混点：同样信息写成自然段或结构字段。首轮不要把“增加信息”与“改变格式”混称为结构带来的收益。

## 4. 一个最小条件记录建议

这只是 M5 中单条条件的候选表示，不是所有卡的公共外壳：

```text
条件内容：原题比较的是自然年龄，而不是任职时长或寿命
当前检查位置：原问题；若语义不明则保持未知
条件依据：来自原题观察／模型归纳假设／独立题反馈支持
不满足或未知时：不直接套用这条操作；允许现场改写或保留原查询
```

**为什么保留检查位置？** 历史题“没有检出第二个人的出生日期”不代表当前题也缺。只有首次检索之后，才有资格检查当前证据覆盖。

**为什么保留依据类别？** 成功轨迹中的共现背景不一定是成功原因；模型总结得像规则，也不等于已验证规则。

**为什么不默认保存全文环境？** 运行级索引、检索器等另存审计配置；卡只保留真正影响动作的条件。不得宣称配置相同就能保证效果相同。

历史可靠性、当前适用性、相对 FRESH 的使用价值分别回答：过去证据多强、现在前提是否成立、现在是否值得多做这一步。它们不能合成一个未经校准的“置信度”后当作事实。

## 5. 可研究的切口：先选一个做实验，不先写成贡献

### 切口 A：保留决策关键条件的压缩

不是追求最短摘要，而是在读取预算下降时，尽量保留“本来该用／不该用”的区别。比较删背景、删条件、删动作的影响；若同信息的自然段表现一样好，就不归功于字段排版。ReMe/QCR 已有表示实验，需要进一步证明查询操作中哪些条件不可替代。

### 切口 B：条件是否能在当前时点检查

把检索前可得和检索后才可得的条件分开。检验未知条件是否比模型猜测更少误用，代价是否是误拒增加。不是简单地“未知一律拒绝”：应同时测有益候选被漏掉多少。

### 切口 C：条件是否为 QPP 提供额外决策信息

固定候选池，对比 QPP、历史查询表现、经验条件、QPP＋经验条件。若条件只帮助选择更长查询而不是更合适的动作，需要长度／实体等诊断。QPP 高不意味着有用，更不等于经验相对现场改写有增量。

建议先以 A 的小型表示实验为方法入口，C 为方向一的后续接入；B 是必须遵守的信息边界，也可单独检验。不把三项又包装为三个平行项目。

## 6. 最小实验与阅读不变的部分

- 先比较 M1/M2/M3/M5；同源、同候选数量、同模型和可见信息、统一 token 上限，并报告实际消耗。不连续 M1→M2→M3 重写，各自直接取原始来源。
- 第一组只换选择器视图，选中后用同一规范动作执行；第二组固定来源，只换改写器视图。这样区分“更会选”和“更会执行”。
- 表示选择实验的拒绝分支建议统一回 FRESH，比较全题策略与 always-FRESH，另报已执行子集 REUSE−FRESH。若选择 BASE/FRESH 也变化，增加同回退政策的无记忆对照。这是实验建议，不改变当前运行代码。
- 同时看救回、改坏、使用率、误拒有益候选、证据指标、答案指标、存储量、写/读卡 token、完整 RAG 次数和时延。未执行的候选没有真实效果标签；需额外离线配对才能评估误拒。
- 沿既定 HotpotQA 官方 train 内独立来源和开发角色；官方 dev/test 不建库。人工构造边界题仅诊断，不能替代自然留出题的效果评价。

阅读建议：**ReFormeR → ReMe → ExpeL → AWM（§2、§3.2.1、§4）→ S2G-RAG → RRM → QCR → QPP Query Variant Selection → ReformIR → RAQG-QPP。** AWM 从旧导读的按需插读提升为表示研究的必读章节，不要求立刻通读全部网页任务实验。

这改变的是学习顺序，不是放弃方向一。先理解历史到底给选择器提供什么，再理解预测器怎样使用它。这几天只需先前三篇；如果已经读了 QPP，不必重读或暂停既有笔记。

精读位置与现成 [12 篇聚焦 RDF/导读](../../zotero/curated/2026-09-08_memory_cards/README.md) 沿用，AWM 已在包内，不再复制出一批同名条目。GAM、Sufficient Context 仍按需插读。GAM 的句子级向量记忆与 S2G 的单题状态都不是同质的自然语言经验卡。
