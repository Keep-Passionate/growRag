# 离线学习、在线应用：2026-09-16 已确认架构

## 本轮定下来的三件事

1. 用户认可离线学习与在线应用分开，作为当前固定架构，不再来回切换总框架。
2. 在线质量优先，默认一轮，必要时允许第二轮；“两轮上限”是首版工程预算，尚非实验选出的最佳超参数。
3. 下一步主任务是确定强FRESH与经验复用的具体方案、控制prompt实验，再学习选择器。离线/在线、差值奖励本身都不宣称首次。

## 架构不是“两座必须分开的记忆库”

离线/在线是工作阶段；QueryEpisode是本题暂存记录，ExperienceCard/模式库是跨题可调用记忆。离线形成一个带版本的库快照，在线读取它。主实验在线不写回长期库，防止测试标签泄漏；本题证据和尝试只进入局部episode。流式记忆更新另开协议与实验。

在线流程：q → PRE选择(BASE/FRESH/REUSE) → 第1轮RAG → 检查本题证据 → 放行，或POST修复选择(FRESH/REUSE) → 第2轮 → 输出有支持答案/说明不足。Reader始终回答原q，不回答被改写后漂移的问题。

“轮”本计划指一次检索＋回答的RAG调用。经验召回、改写、judge、选择器、可选重排分别计调用与时间，不能把两轮写成只花两次LLM。以后若改为多次检索只最后回答一次，必须另立成本协议。

## 思想来源与不是我们的新意

- ReFormeR：从历史查询对离线归纳规则/示例，应用时选择并执行。公开实现的POST文档信息与我们的PRE输入不同。
- ExpeL、AWM：从经验获得可复用知识/流程；AWM还讨论离线与在线获得工作流。它不是我们发明的双阶段。
- Adaptive-RAG：用轻量分类器在不同检索复杂度策略间选择，标签由策略表现构造；我们的动作对象是具体查询修复经验，并非简单重命名复杂度分类。
- ReflectiveRAG、S2G-RAG：用当前证据指导有界修复；既有gap、停止和充分性思路应如实归因。
- RRM/QCR、UMEM、Trainable Graph Memory、MemRL：已有适用性、记忆增量评价、增量奖励学习或效用值更新。详细区别见 ../literature/2026-09-16_离线在线与增量奖励先例核查.md。

## 两轮内FRESH的首版设计（待接通真实评测）

FRESH的定义是不读跨题经验，不是“只准弱提示”。PRE先比较关键词改写和扩写；POST则可以看到本题状态，但不能看到gold。

POST只整理短状态，不保存长CoT：

- 目标：原q要求回答什么；实体/属性/方向/时间约束。
- 已观察支持：真实文档句子ID及其支持的子问题。
- 缺口：尚未找到的关系/属性；不能把没命中gold句等同于没支持。
- 已失败尝试：此前query与返回证据ID，防重复。
- 下一动作：只弥补一个明确缺口，或补全比较双方覆盖；不猜未知桥接实体。

最多2轮；支持充分可早停；重复query、没有新证据或预期增益不足、预算不足、模型/接口异常也终止。停止不等于强行给答案，允许输出部分已支持结论并说明缺口。充分性judge只是有误差的工具，不是正确性证明。

重要实现缺口：当前外循环累计了观测证据，但RetrieverReaderBackend的Reader每轮只看当轮检索结果。正式两轮实验前必须显式接通“有界累计证据→最终Reader”的能力，保留来源、去重和长度预算；不能现在声称第二轮已完整利用第一轮证据。若底座不能返回/接收证据，只能降级，不能声称对任何黑盒RAG都透明支持此能力。

## 历史复用的最小方案

统一外壳保留来源/版本/候选状态；执行正文使用名称、描述、规则、代表例子，补充最少可观察适用条件和不可改动项。description是模式功能说明，不要求LLM把问题/CoT缩写进这一字段。例子可以保留真实q→q′及审计指针；摘要是可实验的一种表示，不是强制结构。

PRE条件只能来自当前q和已知环境；POST条件可用本题检索证据，两个阶段的条件/训练数据不可混充。相似度产生短名单，最终效用预测才决定是否执行；来源成功不等于新题适用。

旧6卡仍是候选，独立迁移未验证。先做表示与适用条件对照，不为了构建漂亮模式库强制合并、反复抽象或强凑10类。

## 公平对照：固定轮数和共同前缀

分别报告1轮组与最多2轮组，不把REUSE两轮对FRESH一轮的差归给记忆。

主要差值：Δ_memory(L)=Score(REUSE策略,最多L轮)−Score(强FRESH策略,最多L轮)，L分别取1、2。同题配对、同底座、同Reader和上下文预算，真实调用成本单列；最多轮数相同不等于实际成本完全相同。

如果研究第二轮“选经验还是现场修复”，第一轮使用完全相同的q、检索结果和本题状态，在该共同前缀上分支。否则分支输入状态不同，会混淆选择与前一步收益。

必要对照：
1. BASE单轮与固定无记忆两轮。
2. 无历史BASE/FRESH自适应路由。
3. 同候选的来源相似度选择。
4. 同候选的历史平均收益选择（MemRL思想适配，不称完整复现）。
5. 同选择器/同规范动作，仅改变卡片表示与适用条件。
6. ReFormeR式POST选模式；其q-only消融单列。

不能在应用时查看所有分支的最终gold分数再挑赢家；那只是付费离线oracle分析。实验若全跑所有分支，费用属于数据收集，不冒充部署成本。

## 具体学习顺序

A：冻结提示词，先找可靠无历史对照。B：固定来源池、动作、选择器，比“怎么记”及逐项删条件。C：用独立配对标签学便宜的增益/风险预测器。D：只有前面证明有稳定信号以后，才考虑RL或7B微调。

EMA维护一个近期均值，不等于线性回归；线性回归拟合输入到收益，不等于强化学习。在线没有合法gold反馈时，不能免费更新“真正确率”，只能记录代理信号并注明其来源。

## 当前待证的中心命题

在同等修复预算下，**当前可观察的适用条件，是否比来源相似度或一条全局历史成功率，更能区分同一个历史动作在哪类新题有增益、在哪类新题有害？**

这是一项可检验问题，不是因为有两阶段、三分支或结构化卡就自动新颖。UMEM等直接近邻必须进入差异审查。结果应同时报告救回、损害、误拒、实际复用比例和额外成本，防止“永远不用记忆”退化。
