# Search-R1：读前导读

## 一句话理解

Search-R1 把 ReAct 中“什么时候搜索、搜索什么、何时停止”从提示词规定的动作，变成一个可以通过最终答案奖励学出来的策略。

## 前置知识与已读论文

先回忆 01 ReAct：它开放了 `<think> → <search> → observation` 的动作空间，但主要依赖提示或人工轨迹。再回忆 09 Self-RAG：它用监督学习得到特殊 token，决定是否检索和怎样评价证据。Search-R1 更接近 DeepSeek-R1：不给正确搜索步骤，只根据最终答案是否正确做强化学习。它与 02 Reflexion 不同，因为失败不会被总结成跨任务保存的自然语言经验。读完后必须接 21 ReasonRAG，后者正面修补 Search-R1 的稀疏奖励与信用分配。

## 方法怎样运行

模型先在 `<think>` 中推理；缺知识时生成 `<search>查询</search>`；环境默认返回前三篇文本，用 `<information>` 插入轨迹；模型看到新信息后继续 Thought、再次搜索，或在 `<answer>` 中结束，最大动作预算为 4。这里 Observation 不是简单增加文本：它改变后续 token 的条件分布，使模型能够改写查询、补齐推理链或停止搜索。若动作格式错误，系统会插入固定提醒 “My action is not correct. Let me rethink.”

关键训练细节是 retrieved-token loss masking。一条 rollout 同时包含模型生成的 Thought、Query、Answer，以及环境返回的文档。只有前者是策略动作，后者不能被当成模型自己生成的 token 计算策略梯度和 KL，因此必须遮蔽。奖励非常简单，也非常稀疏：只抽取最终 `<answer>`，与标准答案做 Exact Match；没有格式奖励、没有搜索过程奖励，也没有神经奖励模型。训练只混合 NQ 与 HotpotQA，测试覆盖七个通用及多跳 QA 数据集。

## 关键证据

7B Base 的平均 EM 从普通 RAG 的 0.304、拒绝采样的 0.348，提高到 0.431；14B 达到 0.479。PPO 收敛较慢但更稳定，GRPO 较快却可能出现奖励坍塌。第 9 页中，7B 模型遮蔽检索 token 后平均 EM 为 0.431，不遮蔽只有 0.343，说明 Observation 可以改变决策，但不能被错误当作动作优化。附录显示 top-3 优于 top-1 和 top-5：检索过少缺证据，过多引入噪声。摘要中的相对提升口径与部分表格并不完全一致，引用时优先使用表格绝对值。

## 局限与失败案例

第 23 页模型已经找到 “The Blue Album”，却最终回答 “Weezer”；第 25、27、31 页分别展示错误证据、重复无效查询和无关文档误导。最终 EM 无法判断中间哪步可靠，也可能奖励“过程错误但碰巧答对”的轨迹。实验只评价问答正确率，没有系统评价搜索成本、引用真实性、经验迁移或长期记忆；所谓实时搜索实验使用的是固定 Wikipedia 语料，而非真正开放网络。

## 对 GrowRAG 的帮助

可以借用它的交错动作空间、环境 Observation、动作预算和 retrieved-token masking，也可以把“读取经验、查询经验、继续探索、给出答案”定义成明确动作。但绝不能把一次答案正确直接等同于轨迹中每条教训都值得写入。GrowRAG 的经验价值门至少还要检查证据支持度、经验新颖性、与旧经验的冲突、检索和 token 成本，以及后续新题上的复用增益。

Search-R1 通过参数更新改变未来搜索策略，GrowRAG 通过外部文本经验改变未来动作。这提供了一个强对照：在相同底座、检索器、动作预算和成本下，比较“RL 参数学习”“无训练经验账本”“二者结合”。还要区分环境 Observation 与可持久化经验：前者只要能改变当前后续决策即可，后者必须经受跨题价值验证。
