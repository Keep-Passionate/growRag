# GrowRAG 知识库

本目录只保存当前研究可以依赖的知识与决策。

- `CURRENT_PROJECT_MEMORY.md`：每轮首先读取的项目记忆。
- `decisions/`：已决定、待决定及被否决的路线。
- `literature/`：文献覆盖、共同缺口及旧精读资产。
- `datasets/`：数据集标注、划分与阶段用途。
- `method/`：方法候选、术语和可选模块。
- `experiments/`：可证伪实验、止损门和结果记录。

原则：把“证据”“推断”“建议”“已决定”明确分开；讨论稿不得自动升级为定稿。
