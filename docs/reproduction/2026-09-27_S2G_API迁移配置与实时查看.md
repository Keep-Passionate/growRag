## 4. 查看结果，不重新调用模型

```powershell
Get-Content 'D:\project\GrowRAG\runs\2026-09-27_s2g_author_api_debug8_v1\summary.json' -Raw

```

- `events.jsonl`：每轮原问题、缺口、查询、文档、选择的原句、原始输出。
- `api_audit/*.json`：真实HTTPS请求内容、返回内容、response/request ID、模型、token、开始/耗时、失败状态；不保存Authorization密钥。
- `request_journal/*_intent.json`：请求前预留与fingerprint；请求后写after，便于发现中断。
- `process.json`：进程、命令、启动时间。
- `source_snapshot.json`＋`launch_plan.json`：本次执行代码、模型/作者哈希与配置。
- `questions/NNN/report.json`：BASE/S2G完整输出后才加入gold评分，包含对错；失败配对不算EM0。

保留证据的support recall采用“作者选句→原Hotpot句子”的**精确文本对齐**；分句不一致会漏计，不能当语义充分率或官方完整support评分。原文检索覆盖与抽取保留覆盖分别报告。

本地日志是可审计执行记录，但不是第三方公证。可结合百炼控制台的调用量、时段及请求ID核对；不把我口头说“运行了”当唯一证据。

## 5. 暂时不需要SSH；真正需要时的服务器规格

当前三个模型角色走API，小池BM25在CPU运行，本机足够。24GB RTX4090不会加速远程API，不为此租卡。

若以后加载作者3B Judge/训练小模型，建议Linux、24GB GPU、64GB RAM、200GB以上可用SSD起步；这是工程预估，是否需要更多磁盘由实际语料/索引大小决定。全本地3B＋8B并发不保证24GB足够，需要量化或分时加载，48GB更宽裕。

需要时我会向你要SSH主机、端口、用户名及本地私钥路径（不要在聊天贴私钥），先显示精确远端命令，再执行。远端同样保留上述文件，可用：

```bash
tail -n 30 -F /实际项目路径/runs/实际运行名/live.log
ps -p 实际PID -o pid,lstart,etime,%cpu,%mem,args
nvidia-smi -l 2
```

以上Linux路径/PID是模板，目前没有远端服务器、没有SSH连接或GPU运行声明。
