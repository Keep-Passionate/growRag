## 2. 先找最直接的近邻

| 要解决的疑问 | 优先读哪些 | 阅读时不能跳过什么 |
|---|---|---|
| 成功 query 能否提炼为复用模式 | **H029 ReFormeR**、H014 Query Rewriting、H030 配对数据 | 模式如何产生、用什么反馈、选择时已经看到了什么 |
| 如何选经验，而不只是找相似题 | **H024 RRM、H004 ReMe、H059 QCR**；S02 EPR | 适用条件、重排/适配、无经验基线、经验移除和独立新题结果 |
| 具体经历如何压缩且不丢前提 | **H025 Useful Memories、H059 QCR**；S05 AMA-Agent | 来源、目标重绑定、前提失效；不能把“摘要加条件”单列创新 |
| 工作流/Agent 思想从哪里来 | **S01 ReAct、H038 AWM**；H037 ExpeL、S04 Voyager、S05 AMA-Agent | 运行时观察与跨题工作流是两个层面，步骤化不自动是新算法 |
| 什么时候不用经验/不改写 | **H027 按需调用的 ExpWeaver、H050 QPP**、H015 Adaptive-RAG | 不用经验、不改写、不检索不等价；H027 不能借用 H061 的 ICML 状态 |
| 怎样判断证据足够并停止 | H062 Sufficient Context、H013 Self-RAG、H018 S2G-RAG、H017 Verma ReflectiveRAG | 充分性、正确性、证据增量、停止原因要分开 |
| 怎样给经验记功 | H023 GAM-RAG、H024 RRM；S06 Hindsight、S07 TreeMem、S08 HiMPO | 比较的干预单位是什么；“来源答对”“条目存在效果”“查询操作贡献”并非同一标签 |

“优先排重近邻”表示需要正面对比，不表示这些论文已经全部被移植到 GrowRAG。AMA-Agent 虽不是首轮必需实现，但其前提/依赖机制必须在确定创新前核对，不能仅因它复杂就忽略。
