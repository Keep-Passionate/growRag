# Sufficient Context

## 我们最需要掌握的 3 点

- 文档是否足以回答问题，与模型最终答没答对，是两个标签。
- 证据不足也可能猜对，证据足够也可能读错。
- 充分性判断器会犯错，冻结提示词只是控制变量。

## 原文与发表状态

[Sufficient Context: A New Lens on Retrieval Augmented Generation Systems](https://proceedings.iclr.cc/paper_files/paper/2025/hash/33dffa2e3d2ab74a783d1a8c292f66d9-Abstract-Conference.html)，ICLR 2025，已审稿的机器学习顶会论文。

## 用容易理解的话说

判断“给出的上下文是否包含回答所需信息”，并单独观察读者如何使用信息。这样能区分检索没找到、证据其实足够但回答没做好，以及模型凭内部知识碰巧答对。

## 精读定位

先读 sufficient context 的定义与判定方法，再读充分性与正确性组合的结果分析。记录 judge 看到了什么、输出是什么，不能只记它的自评分。

## 对 GrowRAG 有什么用，不能据此说什么

经验录入应保留答案层和证据层反馈。找回标注支持句是可审计代理指标，但不完全等于充分性：可能有其他有效证据，也可能句子齐全却关系未建立。

这篇支持“分层定位错误”，不提供数学意义正确性保证。首次检索前还没有新题文档时，不能假装已经判断其证据缺口。充分性更适合离线教师过程，或未来可选的检索后修复分支。
