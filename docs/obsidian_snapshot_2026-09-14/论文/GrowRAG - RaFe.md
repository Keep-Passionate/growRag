# RaFe

## 我们最需要掌握的 3 点

- 无人工答案时，可以借排序器反馈训练改写器。
- 排序反馈是代理信号，不是“最终答案一定正确”。
- 完整方法包含训练，不能只复制提示词就叫 RaFe 复现。

## 原文与发表状态

[RaFe: Ranking Feedback Improves Query Rewriting for RAG](https://aclanthology.org/2024.findings-emnlp.49/)，Findings EMNLP 2024，已审稿；不是 EMNLP 主会论文。DOI：10.18653/v1/2024.findings-emnlp.49。官方页面附软件包。

## 用容易理解的话说

改写器需要知道怎样的 query 更有用，但人工标注文档和答案代价高。RaFe 使用现成 reranker（重排序器）产生排序反馈来引导训练，支持在线和离线训练方案。

这减少对特定人工标签的依赖，不等于完全没有监督信息：排序器本身提供了一种学习信号，也可能偏好有偏或偏题的检索结果。

## 精读定位

读排序反馈怎样形成、训练流程中的候选与奖励、离线/在线方案和实验消融。重点核查打分比较的是原问题还是改写问题，哪些模型固定、哪些参数更新。

## 对 GrowRAG 有什么用，不能据此说什么

适合在拥有一批配对数据后研究低成本小改写器，或作为无需标准答案的反馈候选。当前先把它与答案层、证据层反馈分开记录，不把 reranker 分数直接当经验可靠性。

首轮用 API 提示方式建立强 FRESH 更容易启动；RaFe 完整训练另列阶段。改写训练成本也要计入，不能只报告推理更便宜。
