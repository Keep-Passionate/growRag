# GAM-RAG

## 我们最需要掌握的 3 点

- 分清历史状态、当前匹配和不确定性。
- 更新力度不应只由“用了多少次”决定。
- 文中的 gain 更新系数不是我们的 REUSE−FRESH 差值。

## 原文与发表状态

[GAM-RAG: Gain-Adaptive Memory for Evolving Retrieval in Retrieval-Augmented Generation](https://icml.cc/virtual/2026/poster/65843)，ICML 2026，正式会议记录已核验。[作者原文](https://arxiv.org/html/2603.01783v1)。

## 用容易理解的话说

它维护与任务和时间有关的句子级向量记忆，并根据当前状态与不确定性调整更新。研究对象偏向检索语料的记忆表示，不是把自然语言操作写成历史查询卡片。

## 精读定位

重点读 §3 的句子级记忆、任务/时间信息、当前匹配与更新系数；沿公式追踪每个量来自历史统计还是当前观察。再读更新相关消融，而不只看总成绩。

## 对 GrowRAG 有什么用，不能据此说什么

可以启发未来卡片可靠性和更新力度的设计，但不要把向量更新公式直接贴到卡片上就声称方法等价。EMA 是平滑历史观测的一种工具，不是保证正确性的机制，也不是所有论文统一采用的淘汰算法。

首轮我们冻结经验与可靠性，只比较表示；动态维护应单独实验。前人已有当前匹配与可靠性处理，不能宣称只有我们考虑这些因素。
