# ReMe｜Remember Me, Refine Me

## 我们最需要掌握的 3 点

- 将“发生在什么场景”和“应该怎样做”分开记录。
- 区分找出候选经验、判断当前适用、实际执行三件事。
- 用使用效果维护记忆，而不是让历史成功永久保鲜。

[Remember Me, Refine Me: A Dynamic Procedural Memory Framework for Experience-Driven Agent Evolution](https://aclanthology.org/2026.findings-acl.829/)，Findings ACL 2026，已审稿；不是 ACL 主会长文。[作者原文 v2](https://arxiv.org/html/2512.10696v2)。

## 用容易理解的话说

经验不仅有正文，还带场景、关键词、置信度和工具信息。这些内容分别帮助检索、适配和维护。记忆的价值来自对后续任务的帮助，不是摘要写得像规则就自动可靠。方法还根据使用与成功等反馈维护低效经验。

## 精读定位

读方法中的经验字段、场景索引、当前任务适配，以及 §3.4 的维护；再看表示和索引消融。把“用于检索的文本”与“给执行模型的文本”用不同颜色标出。

## 对 GrowRAG 有什么用，不能据此说什么

可作为 M2 强摘要与 M5 条件卡的设计参考。摘要对照也应该允许保存重要条件，不能故意做弱，再证明卡片好。

场景条件、经验压缩和动态维护均已存在。GrowRAG 需要额外验证：某条件是否帮助判断当前查询上 REUSE 相对 FRESH 的价值。首轮冻结卡池，不同时启动淘汰，否则无法分清表示和更新带来的影响。
