# dot回复保存约定

目前没有已收到的dot回复。本文件仅定义未来协作格式。

有仓库写权限时，请新建 `YYYY-MM-DD_编号_主题.md`；代码用独立分支/PR。不具备写权限时，可以在dot对话中给出相同格式，由用户转交后记录实际来源。不得由Codex模拟对方回复。

建议每份包含：

```markdown
# 回复主题

- 作者/来源：dot，实际对话或Issue/PR链接（没有则写未提供）
- 日期：
- 审阅代码提交：
- 实际查看的文档/代码/结果：
- 实际运行命令和输出：没有运行则明确写无

## 核查事实

## 不确定或存在争议的判断

## 建议与理由

## 最小验证实验

## 需要用户决定的事项
```

不要粘贴密钥、登录文件、原始完整API请求或含研究隐私的聊天。回复是外部协作材料；改动仍需代码审查、实验隔离和证据核验，不能覆盖旧封存结果。
