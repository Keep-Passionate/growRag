# 动态算子：结构化输出 v2 校准与迁移闸门

## 最需要先理解的事

**当前修的是模型与执行器之间的格式协议，不是通过看测试答案改方法。** 旧版遇到的 STATIC 错误是“说停止，却同时创建一个动作”。不能猜它的意思，也不能删掉错误字段后把本题记为成功。

`legacy-v1` 保留原方法。`structured-v2` 是隔离的新配置，先仅开放校准阶段；模型、检索底座、动作表达能力和检索预算不因此升级。新配置在真实 API 上的兼容性与问答效果，必须分别验证，不能由单元测试代替。

## Material Passport

- 工作流：academic-research-suite / experiment-agent，代码实现及离线验证。
- 起点证据：来源第 28 道题 STATIC 返回合法 JSON，却包含互斥的 STOP 与非空 operator；旧记录保持不变。
- 数据权限：来源 500 / 校准 100 来自官方 train；评测 500 来自官方 dev。校准不建卡，评测继续封存。
- 预算：延续用户的新授权，本项目按累计 200 元执行；不清除旧失败或未知费用。
- 本文是迁移计划与审计边界，不是实验结果。下方的真实兼容测试尚未执行。

## 1. 哪些内容改变，哪些不改变

| 内容 | 新配置处理 | 原因 |
| --- | --- | --- |
| 模型输出 | 为 FRESH、STATIC、MEMORY、Reader 分别登记固定 JSON Schema | STATIC 不能获得创建动作的输出字段能力；FRESH 不选历史 ID |
| 简短理由 | 有限诊断标签，不再输出长段自由说明 | 避免把解释文本当执行协议或生成冗长自述；标签不是正确性证明 |
| 动态 gap 字段 | 使用 `gap_entries` 名值列表，严格转回原 gap 字典 | 固定外壳仍允许新动作拥有自己的参数，不能只为格式稳定而阉割动态能力 |
| 重复字段/错误类型 | 明确拒绝，不截断、不猜测、不把字符串转布尔值 | 保留失败的可解释性，避免隐性修补改变算法 |
| 真实原始响应 | 单独保存，另记规范化对象 | 可以追查执行对象如何从响应形成；规范化不冒充原始返回 |
| 检索与动作语法 | 维持当前 DSL、top-6、最多 3 次检索、2 次决策 | 不把预算增加造成的收益误算为格式或记忆收益 |
| 旧实验 | 原预测、claim、方法 SHA 和失败都保留 | 新版本不能自动释放旧失败题或混入原来的来源统计 |

阿里云文档区分 JSON Object（有效 JSON）与 JSON Schema（字段结构约束），当前列出 Qwen3.7-Flash 支持后者：[官方结构化输出说明](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。结构正确仍不保证证据充分、关系正确或动作有用；本地互斥、来源引用和预算检查不能删除。

文档建议避免输出上限引起 JSON 截断；本实验仍保留显式 token 上限来约束费用。若达到上限，一律保存并报告失败，不补全 JSON、不静默重试。是否需要更改上限必须作为新配置记录。

## 2. 先验证格式，再验证方法

```text
虚构夹具：格式/类型/条件/泄漏/账本回归
    ↓
未用校准题：少量真实格式兼容测试，不读 gold、不建卡
    ↓
独立下一批校准题：冻结配置后的稳定性观察
    ↓
确认新版本采集政策，接通来源评分/四库/冻结/评测全链
    ↓
来源 500 → 各规模独立建库 → 冻结 → 评测 500
```

候选校准批次为固定顺序的第 9–16 题（索引 8:16）；实际执行前必须由全版本 claim 检查确认未启动。若第一批通过，可再固定 16:32 作为下一批稳定性观察。失败照录，不因为难题或格式差换题、不多次试到成功才保留。

校准需要报告每组：启动/完整/格式失败/网络失败数、真实请求数、input/output token、已知费用与未知请求。8 或 24 题无错误也不能保证未来 500 题无错误，不作强统计结论。

## 3. 本轮明确关闭的入口

- `structured-v2` 暂不接受 source、evaluation、memory 组、banks 或旧 resume 证书；必须在读取这些数据前拒绝。
- 两版共享付费串行锁与项目账本；不同 prefix 不意味着可以重跑旧已启动题。
- 新版代码/Schema 都进入新方法指纹；旧版 9 份方法文件和签名语义不回写。
- 此隔离入口只是迁移第一步，不代表 PDF 的 E1、E3 或独立 repair 确认已经实现。

## 4. 后续研究不因格式修复而改变

仍然分别回答：历史动作是否提供强 FRESH 之外的机会；执行前可见信息能否选中；有用的究竟是适用条件，还是更多文本、候选或检索。

迁移成功后，应先固定方法，再完成独立来源轨迹与四种来源规模建库。正式效应比较必须使用同版本的 FRESH/STATIC/MEMORY，不能拿 v2 的成功题对比 v1 的失败题后宣称记忆有效。
