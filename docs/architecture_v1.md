# GrowRAG 最小研究架构 v1

设计日期：2026-09-06。先定义职责与实验协议，再接通实现。本文记录既有单步配对设计，不是方法效果声明。

最新阶段：用户认可图的总体方向，已允许最小编码与本地训练。新增 [前置查询层＋独立 RAG 外循环](../knowledge/decisions/2026-09-06_外置查询层_动作分流与最小实现.md)，代码图见 [SVG](../figures/2026-09-06_outer_loop/code_architecture.svg)。以下既有单步配对骨架保留作研究对照；新循环不等于自动可信路由已完成。小型 QPP 已独立拟合、尚未门控；新循环只有流程测试，无本轮新增 API 效果证据。

## 研究对象与本轮边界

研究对象是“跨题查询修复经验的使用与表示”，不是重写整个 RAG。当前只在同一个首次检索状态下比较：BASE 直接回答；FRESH 不看历史生成一个新查询；REUSE 看一条来源经验生成一个新查询。FRESH 和 REUSE 各最多一次追加检索，回答始终针对原问题。

这是离线配对诊断：为了解哪种动作更好，会执行多个分支。它不是已经部署的自动路由器，也不能把多分支花费隐藏为单支在线成本。先不实现多轮 agent、小模型训练、EMA、三层联动或遗忘合并。

## 六个职责与数据边界

| 部分 | 功能 | 不能做的事情 |
|---|---|---|
| 数据与划分 | 导入数据，按稳定规则隔离经验来源、选择器训练、校准与冻结评价 | 不能把官方开发集反复当调参集后又声称未见测试 |
| 检索 | 冻结候选语料，执行 BM25，记录版本、证据 ID | 不能偷用支持标注选择文档；候选池不冒充 fullwiki |
| 模型接口 | 固定快照和 prompt，生成 gap、query、answer 与紧凑经验 | 不允许隐式换模型、自动重试、调用失败用假答案补齐 |
| 经验存储 | 不可变来源记录；成功来源的程序性笔记；当前问题选择 | 不允许目标题更新来源库，历史答案不作当前事实 |
| 配对执行 | 共用首检快照，隔离 BASE/FRESH/REUSE，记录退化与调用 | 不以目标 gold 选经验，不让分支共享新增证据 |
| 评价审计 | 运行后评价答案 EM/F1、支持句增量、成本、失败；保留逐题结果 | 引用存在不等于蕴含支持，少量题不是论文结论 |

依赖顺序：数据输入 → 本地首检 → 固定 prompt 描述当前缺口 → 三分支 → 隔离 gold 评价。源题评价完成后才允许生成候选经验；目标题阶段冻结源库。

## 最小功能设计

- QueryEpisode：一道题的首检状态、分支动作、证据、答案、反馈与成本，作为不可变来源。
- ExperienceCard：从合格来源轨迹提取程序性操作、适用条件，带 source_query_id/source_step_id；实验首版不把它叫永久可信。
- DocumentSession：保留设计、暂不激活。QASPER 的文档内学习另立实验。
- 初版选择器只是可审查的词汇相似度对照，不宣称为我们完整的“可信选择”算法；QPP 和前提匹配后续单独加。
- 结构化 gap 只看原问题和首检证据，不看参考答案或尚未检索到的文档。Judge 输出是代理判断，不是 gold。
- 来源录入暂用保守规则：FRESH 答案正确且取得新标注支持；保留 BASE 差异，避免把“正确”误称净收益。
- 空经验库如实记录，不能人为塞进看过目标答案的经验凑结果。
- 修复重复/无效时保留停止原因；实际策略回退与原始分支结果分别报告，不能悄悄丢掉难题。

## 数据与本轮试跑

优先 HotpotQA；随后 2WikiMultihopQA 验证结构化关系、MuSiQue 检验更长推理链；文档层用 QASPER 后置。正式数据协议另文记录。官方划分保留，train 内部分配约 80% 经验积累、10% 选择器学习、10% 开发校准；这一比例是项目设计，不伪装成某论文规定。

本轮只取 train 中少量源题与开发校准题，题号在首次模型调用前冻结，官方 dev 不参加本轮调试。候选句检索只用于排错，不与 fullwiki 论文数字直接比。模型沿用已连通的 qwen3.7-flash-2026-07-15，关闭思考；至多 8 个来源题＋8 个目标开发题、96 次调用，保守请求预算限制在 1 元内，不购买套餐、不大规模运行。

## 工程与版本控制

- 重用已有轻量实验骨架，不以旧 facade 决定新架构；暂不复制上游仓库实现，不虚称复现了 RRM/S2G。
- 纯逻辑测试与真实 API 实验分离，CI 不读取密钥、不访问付费接口。
- `data/`、`runs/`、密钥文件不提交；提交代码、非敏感配置、协议和脱敏汇总。
- 分支采用 `codex/` 前缀；提交前运行测试、静态检查、秘密扫描；推送不使用 force。
- 当前未选择开源许可证，不擅自添加授权。公开代码不等于已授予任意再分发许可。
- 固定代码 commit、数据文件哈希、划分种子、模型快照、prompt 版本与调用日志；API 随机性仍可能存在，不能承诺完全一致输出。
